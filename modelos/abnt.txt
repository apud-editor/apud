# ==============================================================================
# Modelo do Apud: ABNT
#
# ABNT = Em branco + diferenças: o que este modelo não diz vem do modelo
# Em branco (modelos/em-branco.txt).
# Normas: NBR 14724:2024, NBR 6023:2025, NBR 10520:2023, NBR 6024:2012, NBR
# 6027:2012 e NBR 6028:2021.
#
# Cada linha é um valor:   propriedade: valor | origem | situação
# Cada seção (== ... ==) é um elemento da árvore. A situação é opcional:
#   (nada)          confirmada na norma
#   ajustável       a norma não fixa; o valor é o padrão, e cada trabalho pode
#                   trocar (nos perfis da versão 1 se chamava "faculdade")
#   escolha: a, b   a norma aceita mais de uma forma; o valor é o padrão
#   desligada       guardada para depois; ainda não tem efeito
# O comentário logo acima de uma linha é a decisão por trás do valor.
# As regras do grupo "o que a norma diz" e as de Citações e referências mantêm
# o nome que tinham no perfil da versão 1.
#
# Ao mudar qualquer coisa: aumente a revisão, troque a data e escreva na nota
# da revisão o que mudou. O guia completo está em modelos/LEIA-ME.md.
#
# Histórico: este modelo continua o perfil ABNT da versão 1 (perfis/abnt.txt).
# Revisão 10 (24/11/2026): o perfil virou modelo (versão 2, etapa 1b), sem
# mudar nenhum valor; a situação "faculdade" passou a se chamar "ajustável".
# Revisão 9 (22/11/2026), a última como perfil: Tabela em mais de uma página
# (IBGE, 8.3): número, título e cabeçalho repetidos em cada página, com as
# indicações (continua), (continuação) e (conclusão). A posição das indicações
# é padrão da faculdade.
# ==============================================================================
