# ==============================================================================
# Modelo do Apud: Em branco
#
# A raiz de todos os modelos (decisão 13 da versão 2). A ABNT, a APA e os
# modelos de cada faculdade ou revista são "Em branco + diferenças": o que eles
# não disserem vem daqui. Por isso o Em branco dá um valor a tudo o que o Apud
# aplica, e nenhum valor de formatação fica escrito no código do programa.
#
# Valores neutros: Times New Roman 12, espaço simples, texto à esquerda, sem
# recuo; títulos em negrito, sem número; capa, folha de rosto, página de título
# e resumos desligados. Onde a versão 1 tinha um valor no código para quando o
# perfil não dizia nada ("Fonte:", o filete de 5 cm, "Referências"...), o
# Em branco usa esse mesmo valor.
#
# Cada linha é um valor:   propriedade: valor | origem | situação
# Cada seção (== ... ==) é um elemento da árvore. O guia completo está em
# modelos/LEIA-ME.md.
# ==============================================================================
